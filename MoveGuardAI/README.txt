# MoveGuard AI — iQOO Hackathon HealthTech Prototype

## Run in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. The browser will open the prototype.
6. Click **Run Demo Mode** for the most reliable hackathon presentation.
7. Click **Use Camera** if you want to show camera access.

## Important
This is a hackathon prototype. Demo Mode uses simulated movement data. The product is for wellness/fitness guidance, not medical diagnosis.
