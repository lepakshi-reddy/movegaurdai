# MoveGuard AI Walkthrough

## 60-90 Second Demo

1. Open the MoveGuard AI app.
2. Start Demo Mode to show the privacy-first movement analysis flow.
3. Select **Squat** and show the live score, repetitions, joint metrics, and feedback changing.
4. Switch to **Posture** and show the alignment feedback.
5. Open the weekly report to show movement trends and progress scores.
6. Explain that MoveGuard AI provides wellness and fitness guidance using local-first movement analysis.

## Demo URL

Run `npm run dev` and open http://localhost:3000/.

## Suggested Narration

MoveGuard AI analyzes movement and posture with clear, real-time feedback. Demo Mode uses simulated pose data, while camera analysis is designed around local processing so raw video is not uploaded or stored. Users can review their scores, exercise form, posture quality, and weekly progress in one place.
